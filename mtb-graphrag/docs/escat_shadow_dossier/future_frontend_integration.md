# Integrazione frontend futura

In futuro il dossier potrebbe avere una sezione separata chiamata
**Actionability clinica**. La sezione non deve essere mescolata con il bucket
di compatibilità o con il punteggio V3.

Stati visualizzabili:

- Non valutata;
- Valutazione incompleta;
- Pronta per revisione;
- ESCAT curato;
- Evidenze conflittuali;
- Non applicabile;
- Assessment superato.

Per un assessment curato la UI potrebbe mostrare tier/subtier, framework e
versione, origine, curatore, data, fonte della regola e fonti dell’assessment.
Per `RESEARCH_DRAFT` deve restare visibile l’avviso di revisione manuale e di
assenza di validazione clinica.

Nessuna UI è implementata in questa branch.
