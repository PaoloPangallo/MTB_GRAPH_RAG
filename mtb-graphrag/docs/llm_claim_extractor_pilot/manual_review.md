# Revisione manuale

La revisione tecnica degli output reali non è iniziata: non esistono output
reali da revisionare. Non vengono trattati come risultati i precedenti output
del provider mock.

Quando l'accesso sarà autorizzato, la revisione coprirà smoke test, nuovi
DIRECT, DIRECT persi, CONTRADICTED, output con dropped fields, quote,
SourceUnit, direzione, negazioni, contraddizioni e run instabili.
