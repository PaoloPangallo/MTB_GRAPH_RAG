# Stability

La stabilità LLM reale non è stata misurata: il provider non è configurato e le
75 chiamate previste non sono state eseguite. La precedente harness offline
deterministica è conservata come artefatto storico, ma non viene usata come
evidenza di stabilità di un modello.

Il protocollo futuro confronterà tre run per bundle su valori, quote, SourceUnit,
negazione, contraddizione, validazione e support status.
