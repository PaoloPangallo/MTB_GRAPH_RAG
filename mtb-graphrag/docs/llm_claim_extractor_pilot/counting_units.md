# Counting units

I conteggi sono separati per unità:

- A: CANDIDATE_LEVEL = 40 candidate;
- B: BUNDLE_LEVEL = 25 bundle;
- B: CANDIDATE_LEVEL = 40 candidate;
- B: CLAIM_LEVEL = 14 claim materializzabili;
- C: RUN_LEVEL = 0 chiamate reali su 75 previste;
- C: BUNDLE_LEVEL = 0 bundle eseguiti su 25;
- C: CANDIDATE_LEVEL = 0 candidate valutate con LLM;
- C: VALIDATED_CLAIM_LEVEL = 0 proposte validate realmente.

Non vengono confrontati direttamente conteggi con unità differenti.
