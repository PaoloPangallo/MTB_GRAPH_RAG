# Stabilità di quote e SourceUnit

Sugli 11 slot accettati in entrambe le run (`EXACT_REPRODUCTION` +
`EQUIVALENT_VALIDATED_SUPPORT`):

- 8/11 riproducono esattamente la stessa coppia (SourceUnit, quote) tra
  run 1 e run 2 (`EXACT_REPRODUCTION`).
- 3/11 mantengono lo stesso valore normalizzato ma con quote e/o SourceUnit
  differenti, entrambe validate indipendentemente dal validatore
  (`EQUIVALENT_VALIDATED_SUPPORT`) — il modello sceglie una citazione
  diversa ma ugualmente letterale e ancorata, non una fabbricazione.

Nell'analisi secondaria a tre run: 10/25 bundle mostrano almeno una quote
ricorrente su più run, 11/25 mostrano almeno una SourceUnit ricorrente.
Nessuna quote inesistente o SourceUnit inventata è mai stata accettata in
nessuna delle 50+25 chiamate del pilot (Stadio 1 + Stadio 2) — la stabilità
di provenance qui misurata riguarda *quale* citazione valida viene scelta,
non la sua validità (garantita in ogni caso dal validatore invariato).
