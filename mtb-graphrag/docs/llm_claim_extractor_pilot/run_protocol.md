# Protocollo di run

Il pilot è definito su 25 EvidenceBundle derivati da 40 candidate, con tre run
per bundle. Le run non sono votate e non viene selezionata quella con più
campi. Per il confronto, quando il provider sarà disponibile, run_index=0
sarà la run predefinita dichiarata.

La configurazione C è bundle → proposta LLM → validatore → ClaimSupportVerifier
esistente. Il modello non assegna lo status finale.

Stato corrente: BLOCKED / MODEL_NOT_CONFIGURED; real runs = 0.
