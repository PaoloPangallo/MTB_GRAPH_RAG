# Future runtime/API integration

Una futura API potrebbe aggiungere il dossier come campo read-only e
versionato, mantenendo il payload V3 originale byte/strutturalmente stabile.

Prerequisiti: contratto approvato, persistenza degli extension records,
policy di audit, gestione degli orphan, versioning dei moduli e test di
compatibilità. Nessun endpoint è modificato in questa branch.
