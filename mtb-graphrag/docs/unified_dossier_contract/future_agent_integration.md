# Future agent integration

In futuro l’agente potrà interpretare il caso, chiedere chiarimenti,
selezionare i moduli, invocare il core V3, richiedere document support,
recuperare diagnostic context, richiedere una valutazione ESCAT e assemblare
il dossier canonico.

Non potrà modificare bucket o score, promuovere claim rejected, inventare
provenance, assegnare ESCAT o trasformare un CompanionDiagnostic strutturale
in requisito clinico. L’ESCAT resterà sempre una richiesta/risultato di
curation separata e tracciabile.
