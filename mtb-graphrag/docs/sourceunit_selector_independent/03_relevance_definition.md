# Relevance definition

`DIRECTLY_RELEVANT` means that the unit contains the specific alteration expression and an evidence-bearing statement useful for evaluating the GCA. A negative or resistance statement can still be directly relevant; relevance does not imply support.

`PARTIALLY_RELEVANT` means that the unit contains a useful fragment such as a biomarker, alteration, or intervention but does not independently express the candidate-specific evidence. `CONTEXT_ONLY` is pertinent background without candidate-specific evidence. `NOT_RELEVANT` has no direct use for this GCA.

The labels are deliberately independent of `SUPPORTED`, `UNSUPPORTED`, `RESISTANCE`, `DIRECT`, `AMBIGUOUS`, gates and downstream status. No label changes the GCA.
