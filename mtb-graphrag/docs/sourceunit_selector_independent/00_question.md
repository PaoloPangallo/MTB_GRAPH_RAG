# Independent question

This phase asks whether the frozen deterministic SourceUnit selector generalizes to real GCA/document pairs that were absent from the selector pilot.

The operational chain tested is `real GCA provenance -> live PMID/PMCID fetch -> canonical parser -> SourceUnits -> frozen selector`. Relevance is measured separately from support direction. No runtime integration is performed.

The corpus contains 20 unseen candidates and 20 unseen documents. The candidate/document overlap with the pilot is zero. The gold was frozen before ranking and hashed as `a8e384bf57402932de272e152bee05c6f421aabe2e568efb62835d19cc12d986`.
