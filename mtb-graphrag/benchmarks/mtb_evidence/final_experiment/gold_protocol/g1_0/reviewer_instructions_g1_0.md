# Reviewer instructions

1. Work only from your assigned blind packet and authorized source context.
2. Do not search for another reviewer’s labels and do not infer system output.
3. Assess each `(query_id, claim_id)` independently.
4. Record every required dimension, including unresolved/not-applicable and
   provenance state; do not silently coerce missing information.
5. Set `evaluable=false` only when the claim cannot be evaluated under the
   protocol; in that case bucket must be null.
6. Use the four buckets exactly as defined. Add rationale codes rather than
   changing bucket definitions.
7. Use the pseudonymous reviewer ID supplied by the coordinator.
8. Save and resume through the local annotation tool; do not edit JSONL by
   hand.
