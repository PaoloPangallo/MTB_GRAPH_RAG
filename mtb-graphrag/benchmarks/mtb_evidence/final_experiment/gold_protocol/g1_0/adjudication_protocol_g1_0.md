# Adjudication protocol

Adjudicator C sees only the blind unit, Reviewer A and Reviewer B responses,
authorized sources, and G1.0 definitions. The V3 prediction, score, rank,
gate trace and reason codes remain hidden.

Create an adjudication record only for disagreements or discordant
non-evaluable states. Preserve both original responses, the final response,
the adjudication rationale code, timestamp, and protocol version. Do not
change the rubric based on agreement.
